# Audit Log

**Mode:** Operate

Read-only record of all significant actions: login, views of sensitive data, create/edit/delete, payments, refunds, exports, permission changes. Includes user, timestamp, module, action, and before/after data.

## Sections

- Audit log table with filters
- User/action/module columns
- Before/after data display

# Buku Kas / Ledger

**Mode:** Operate

Complete financial ledger recording every money movement including internal transfers (not counted as omzet/profit). Double-entry bookkeeping: every inflow, outflow, refund, cashback, and transfer is recorded and reflects on rekening balances.

## Sections

- Ledger entries table
- Filter by type (payment, refund, purchase, cashback, transfer, expense)
- Running balance
- Export to Excel/PDF/CSV

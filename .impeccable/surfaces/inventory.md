# Inventory / Stock

**Mode:** Operate

Stock management with permanent history. Statuses: Tersedia (Available), Booking, Akses Terbatas (Limited Access), Terjual (Sold), On Hold, Bermasalah (Problem), Cancel. Full stock history is preserved.

## Sections

- Stock list with status filters
- Add stock modal
- Edit stock modal
- Category filtering
- Status badge system
